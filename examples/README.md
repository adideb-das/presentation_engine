# Examples

Examples show the playbook applied. They never override it.

## What to add
- **Approved presentations** → `gold-standard-presentations.md`: only decks you explicitly approved. Record what was approved and why, not just the file name.
- **Feedback** → `feedback-examples.md`: your actual words, the date, what changed, and which rule it confirms, creates or removes.

## Rules
- Remove confidential material, other people's personal data, and source documents you may not redistribute. Store a description and the slide outline instead of the file if in doubt.
- Never add an example you didn't approve, and never write feedback you didn't give.
- When a feedback entry changes a rule, update `system/master-playbook.md`, then the extracts, then `CHANGELOG.md`.
