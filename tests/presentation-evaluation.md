# Presentation Evaluation Rubric

Score any regenerated deck the same way, so results are comparable over time.

## Scoring (0–2 each; 0 = missing, 1 = partial, 2 = fully met)

| Area | Criterion | Score |
| --- | --- | --- |
| Opening | Biggest risk named before building | |
| Structure | Source framework as spine; dividers; summaries with handovers | |
| Titles | Every title a one-line claim; titles alone tell the story | |
| Density | ≤ 4 bullets; one visual per slide; no pasted multi-panel figures | |
| Evidence | Unit + comparison + source on every number; no invented data | |
| Honesty | Unfair comparisons caveated; unverified values flagged | |
| Critique | One critique slide; Q&A traps in notes | |
| Style | Institutional spec applied consistently | |
| Typography | Body ≥ 18 pt; no overflow, overlaps or two-line titles | |
| Notes | Spoken script with caveats on every content slide | |
| Timing | Slide count and speaker split match the duration | |
| Delivery | File + ≤ 4-line message (contents, to-dos, biggest risk) | |

**Total /24.** 20+ = system reproduced well; 15–19 = usable with fixes; < 15 = restore again with the full playbook (not the compact prompt).
